# 출제 자기검증 체크리스트 (모든 문항 출제 후 필수 실행)

> 이 체크리스트는 에이전트가 문항 출제 후, validate 전에 반드시 수행해야 한다.
> 1개라도 FAIL이면 해당 문항을 수정한 후 다시 검증.

---

## A. 학생 풀이 가능성 (모든 문항)

- [ ] **stem만 읽고 정답을 특정할 수 있는가?** passage 없이 stem만 보고 "무엇을 물어보는지" 명확한가?
- [ ] **passage에서 정답 위치를 찾을 수 있는가?** 서술형이면 학생이 passage 어디를 봐야 하는지 단서가 있는가?
- [ ] **정답이 유일한가?** 다른 답도 가능하지 않은가?

## B. 조건영작/어순배열 전용

- [ ] **[조건]의 "모두 사용"에 나열된 단어 전부가 wa에 포함되는가?** 더미 단어 절대 금지.
- [ ] **wa에 축약형(I'll, don't, can't, won't, they've 등)이 있으면서 stem에 (N단어)를 쓰지 않았는가?** 축약형 + (N단어) 동시 사용 금지.
- [ ] **wa에 콤마 나열(A, B, C)이 있으면서 (N단어)를 쓰지 않았는가?** 콤마 나열 + (N단어) 동시 사용 금지.
- [ ] **[보기] 단어가 정답 순서대로 나열되지 않았는가?** 알파벳순 셔플 필수.

## C. 서술형 찾기형 전용

- [ ] **stem이 Q→A 형식인가?** "Q: [영어 질문]\n→ [답 시작] ___ ___ ___." 형태 권장.
- [ ] **빈칸(___) 개수 = wa 단어 수인가?** 이그잼포유 방식: 빈칸 개수로 답 길이 표시.
- [ ] **wa가 passage에 그대로 있는가?** 찾기 유형이므로 정답 노출 정상이지만, 실제로 있는지 확인.

## D. 태그 안전성 (렌더러 호환)
