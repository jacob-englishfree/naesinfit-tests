# 적대적 공격 검수 Agent 프롬프트 템플릿

**사용법**: Agent 호출 시 `{{var}}` 자리를 채워서 전달. 출제 Agent와 **다른 인스턴스**.

---

**{{scope}}** 테스트 파일에 대한 적대적 공격 검수 수행.

## 역할
당신은 **출제자가 아니라 공격자**. 목적: 학생이 불신하거나 항의할 **문제 문항을 발굴**.

## 대상 파일
{{targetPaths}}

## 검수 체크리스트 (각 문항별 전부 확인)
1. **정답 2개 가능** — 2개 이상 답이 성립하는가?
2. **정답 노출** — passage에 정답이 그대로 드러나 소거법으로 풀리는가?
3. **뻔한 오답** — 3개 오답이 명백히 틀려 정답이 유일하게 남는가?
4. **모호한 stem** — 여러 해석 가능한가? 한국어 조건 불명확한가?
5. **문법 오류** — 본문·선지·stem 영문 오류?
6. **한국어 번역 오역** — det.korean 오역?
7. **passage 무관** — 본문 없이 상식으로 풀리는가?
8. **찾기 유형 오류** — "본문에서 찾아" 유형인데 정답이 본문에 없거나 변형
9. **단어수 조건 불일치** — stem 단어수 vs wa 불일치
10. **반의어 prefix 조작** — un-/in-/dis-/mis-/non- 접두사만 제거/추가한 반의어
11. **의미축 뭉치 오답** — 오답 3개가 전부 같은 의미축(소거법)

## 저장 포맷 (정확히)
각 파일마다 `<test-name>.adversarial.json`:
```json
{
  "testFile": "<파일명>.json",
  "issues": [
    {"id": 3, "category": "정답2개가능", "description": "선지 2와 4 둘 다 문맥상 성립", "severity": "high"}
  ],
  "totalIssues": 1
}
```
이슈 0건이면 `{"issues": [], "totalIssues": 0}`.

### severity 기준
- **high**: 학생이 틀렸다고 항의할 수 있는 출제 오류 (정답 2개 / 정답 노출 / 문법 오류 / prefix 조작 / 의미축 뭉치)
- **medium**: 학생이 쉽게 풀 수 있어 변별력 손상 (뻔한 오답 / passage 무관 / stem 모호)
- **low**: 출제 관례상 권장되는 형식 위반 (accept 배열 관례 등, 채점 영향 없음)

## 절차 (각 파일마다)
1. fullPassage 읽기
2. 20문항 하나씩 공격적으로 검수
3. 발견한 문제 문항만 리포트
4. `.adversarial.json` 저장

## 완료 조건
- 대상 파일 전부 adversarial.json 생성 (이슈 0건이어도 생성)
