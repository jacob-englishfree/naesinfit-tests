# 내신핏 테스트 출제 워크플로우 (Generator)

이 워크플로우는 `TEST-SOP.md`의 STEP 0 ~ STEP 2를 수행하여 JSON 형태의 문항을 생성하고 구조를 1차 검증합니다.

## STEP 0: 원문 확보
1. 사용자가 제공한 교과서/모의고사/수능특강 원문 텍스트를 정확히 확인합니다.
2. `fullPassage` 변수에 이 원문을 저장하고, 오탈자가 없는지 원본과 글자 단위로 대조합니다.
3. 원문 정확성이 최우선입니다!

## STEP 1: 문제가 들어갈 JSON 출제 (Generator)
`출제_가이드라인.md`를 기반으로 다음 규격을 지켜 출제합니다.
- **문항 수**: 사용자 요청에 따른 테스트 종류 (단어 20문항 / 워크북 20문항 / 퀴즈 20문항)
- **배점**: 쉬움(4점)×5 + 보통(5점)×10 + 어려움(6점)×5 = 정확히 100점 맞춰서 배점 (`pts` 필드)
- **선지**: 반드시 4지선다 (T/F 유형만 2지선다)
- **마킹 규칙**: 빈칸형(`__________`), 어법(`①`~`④`), 부적절어휘(`<u>4개`)
- **[절대 금지 사항]**:
  - 정답이 지문에 노출되는 것
  - 더미 선지(해당없음 등)나 5지선다 사용
  - 같은 정답 번호 3연속 등장
  - 원문 변조 금지

## STEP 2: JSON 구조 검증
생성된 JSON 파일을 파일로 저장한 후(예: `data/교과서/...폴더명/테스트명.json`), 아래 명령어로 구조 검증을 진행합니다. (사용자가 실행 권한을 줄지 결정합니다.)

```bash
node validate/validate.js [생성한 JSON 파일 경로]
```
- 오류가 발견되면 자동 수정 또는 재출제 후 검증을 다시 실행합니다.
- 검증 툴에서 에러가 0개로 **PASS** 되어야 출제가 완료됩니다.
- PASS하지 않으면 다음 검수 워크플로우로 넘어갈 수 없습니다.

출제가 성공적으로 완료되면 `verify_questions` (검수 워크플로우)를 시작하라고 안내해 주세요.
