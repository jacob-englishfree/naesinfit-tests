# 내신핏 테스트 검수 워크플로우 (Solver, Verifier, Breaker)

이 워크플로우는 `TEST-SOP.md`의 STEP 3 ~ STEP 8을 수행하여 출제된 테스트를 철저하게 검수하고 최종 배포를 준비합니다.
`generate_questions` 워크플로우가 끝난 뒤 (구조 검증 PASS 상태) 진행해야 합니다.

## STEP 3: 블라인드 풀이 (Solver) - 매우 중요!
1. 에이전트(LLM)는 JSON에서 `ans`(객관식 정답), `wa`(주관식 정답) 필드를 **안 본 상태에서** 지문(passage), 발문(stem), 선지(ch)만 보고 **직접 문제를 풉니다**.
2. **20문항 전부 풀이 및 근거를 작성**하여 화면에 출력합니다.
  - 출력 양식 (필수 제공): 
```
=== 블라인드 풀이 ===
Q1 (빈칸 어휘 완성, 보통/5점)
  지문: The researcher tried to __________ the results...
  선지: ① replicate ② generate ③ eliminate ④ distribute
  풀이: 연구자가 결과를 복제하려 했으므로...
  내 답: ①
```

## STEP 4: 정답 대조 (Verifier)
1. STEP 3에서 직접 푼 답과 JSON에 기록된 원래 정답(`ans`, `wa`)을 비교합니다.
2. 20문항 전체에 대해 **일치/불일치 표**를 출력합니다.
3. **불일치가 하나라도 발생하면**:
    - 출제가 틀렸는지(정답 수정), 내 풀이가 틀렸는지(난이도·모호성 등 문제) 재검토!
    - 문항이 잘못되었다면 해당 문항 폐기 후 재출제하고 **STEP 3부터 다시 반복**합니다.

## STEP 5: 적대적 공격 (Breaker)
**"이 테스트에서 오류를 찾아라"는 역할로 전환하여** 아래 체크리스트를 확인하고 결과를 출력합니다.
- [ ] 정답이 2개 이상 가능한 문항이 있는가?
- [ ] 선지가 너무 뻔한 문항이 있는가?
- [ ] 정답 단어가 지문에 노출되었는가?
- [ ] 어법 문제에서 문법 포인트가 실제로 존재하는가?
수정 사항이 발견되면 JSON을 고치고 **반드시 STEP 3(블라인드 풀이)부터 다시 실행**합니다.

## STEP 6: 최종 자동 검증
아래 3가지 검증을 전부 실행하여 PASS 여부를 확인합니다.

```bash
node validate/validate.js [JSON 파일 경로]
```
```bash
node validate/validate-fulltext.js [JSON 파일 경로]
```
```bash
node validate/validate-scoring.js [JSON 파일 경로]
```
- 모든 검증에서 PASS해야 합니다. (FAIL 시 항목 수정 후 재실행)

## STEP 7: 증적 리포트 출력
최종 통과 시 아래 형식으로 리포트를 작성합니다. 리포트 없이는 배포할 수 없습니다.
```
══════════════════════════════════════════
  테스트 검증 리포트
  파일: [파일 경로]
  생성일: YYYY-MM-DD
══════════════════════════════════════════
[STEP 2] 구조 검증: ✅ PASS
[STEP 3] 블라인드 풀이: 20/20 풀이 완료
[STEP 4] 정답 대조: 20/20 일치 ✅
[STEP 5] 적대적 공격: 이슈 0건
[STEP 6] 자동 검증: (validate/fulltext/scoring 모두 PASS)

최종 판정: ✅ 배포 가능
══════════════════════════════════════════
```

## STEP 8: 배포 준비 및 안내
리포트 출력이 완료되면, jacob(관리자/사용자)에게 보고합니다. 명령어를 직접 안내합니다.
```bash
node scripts/deploy.js [파일경로]
```
